# Epistemic Alignment

Epistemic Alignment is a Codex plugin for building a shared, auditable
understanding of a complex initiative before implementation planning starts.

The package will provide `alignment:*` skills and a deterministic `alignment`
helper. The initial helper boundary is available through either command:

```sh
scripts/alignment --version
python3 -m epistemic_alignment.cli --version
```
