# Glossary

- **Export** — The workflow subject to the Finance and Support requirements.
- **Irreversible** — A completed export cannot be undone, per `STMT-FIN-001`.
- **Cancellation window** — A period during which Support requires cancellation
  to remain possible, per `STMT-SUP-001`.
- **Current statement** — Human-confirmed input that remains active; it is not
  an implementation approval.
- **Conflict** — `CON-001`, the unresolved tension between irreversibility and
  a cancellation window in the same export flow.
