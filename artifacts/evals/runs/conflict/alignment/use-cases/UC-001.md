# UC-001 — Export a record

**Scope:** Proposed export workflow
**Primary actor:** Export operator
**Stakeholders and interests:** Finance requires completed exports to be
irreversible; Support requires a cancellation window.
**Preconditions:** An export request exists; `CON-001` is unresolved.
**Trigger:** The operator starts an export.
**Minimal guarantee:** No export policy is silently chosen while the conflict
is unresolved.
**Success guarantee:** Pending `OWNER-COO-001` resolution, the workflow will
apply the explicitly decided lifecycle policy. No success behavior is approved
by this dossier.
**Main success scenario:**

1. The operator submits an export request.
2. The workflow consults the policy selected by the COO.
3. The workflow applies the decided cancellation and completion semantics.

**Extensions:**

1a. If `CON-001` remains unresolved, the workflow stops before an irreversible
   export action and records the need for a decision.
